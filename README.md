# 成珊珊 · 个人成长主页

一个面向软件工程（AI 大模型）专业学生的个人成长主页，包含关于我、学习记录、技能展示、项目作品、联系方式和内容编辑页。

## 功能

- 5 个页面，统一导航，可互相跳转
- 关于我：姓名、专业、年级、学习方向、一句话介绍
- 学习记录：时间线、搜索、状态筛选、标签筛选、排序、展开收起
- 技能展示：文字说明 + 代码片段 + 截图 URL 作为证据
- 项目作品：问题、职责、技术、最大困难
- 联系方式：邮箱、GitHub，不含手机号和家庭住址
- 联系表单：前端校验与提交成功提示
- 编辑页：填写内容、增删学习记录/技能/项目、保存到 localStorage、导入导出 JSON
- 响应式布局，支持手机宽度
